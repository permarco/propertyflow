# PropertyFlow Agent Instructions

The repository-wide AI instructions for PropertyFlow are defined in:

- `.github/copilot-instructions.md`

Before generating, modifying, reviewing, or refactoring code in this repository,
read and follow the instructions in that file.

The project documentation under `/docs` is the source of truth for:

- vision and scope
- architecture
- architecture decisions
- quality requirements
- security constraints
- AI guardrails

Do not invent requirements or architectural decisions that are not supported by
the project documentation.

If a requested change conflicts with the documented architecture or constraints,
do not silently implement it. Point out the conflict and propose an explicit
documentation or ADR change first.
