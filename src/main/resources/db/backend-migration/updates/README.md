# Weitere Schemaänderungen

Neue Änderungen beginnen mit **V9** und werden hier abgelegt, zum Beispiel
`V9__caseprocessing_example.sql`. Versionsnummern sind backendweit eindeutig.

Die fünf Initialdateien stehen in den Modulordnern. Bereits angewendete Initial-
und Folgemigrationen bleiben unverändert. Nach dem freigegebenen Hard Reset gibt
es keine Legacy-Kette und keine reservierten historischen Versionsnummern mehr.

Aktuell angewendet: V6–V8 (Konten, Fallzugänge, administrative Befehle). Nächste freie Version: V9.
